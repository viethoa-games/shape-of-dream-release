# Shape of Dreams — Việt hóa (Vietnamese Localization)

> 🇻🇳 Bản Việt hóa **không chính thức** cho **Shape of Dreams** (Lizard Smoothie).
> **Việt hóa bởi Tấn Nguyễn — tannguyenvnkg@gmail.com** (contact for work)

[![Latest release](https://img.shields.io/github/v/release/viethoa-games/shape-of-dream-release?label=Tiếng%20Việt&color=red)](https://github.com/viethoa-games/shape-of-dream-release/releases/latest)

## Tải & cài đặt

1. Vào **[Releases](https://github.com/viethoa-games/shape-of-dream-release/releases)** → tải file
   `ShapeOfDreams_VI_vi-VN-<version>.zip` mới nhất.
2. Giải nén, chép thư mục `Mods\ShapeOfDreams_VI` vào `<thư mục game>\Mods\`:

   ```text
   Shape of Dreams\
   └── Mods\
       └── ShapeOfDreams_VI\
           ├── about\        (icon, mô tả, metadata)
           ├── bin\          (mod DLL)
           └── locales\      (vi-VN.json)
   ```

3. Mở game → **Mods** → bật **Vietnamese Localization (Tiếng Việt)**.
4. Vào **Language** → chọn **Tiếng Việt**. (Chỉ cần chọn 1 lần, các lần sau tự giữ.)

> Yêu cầu: Shape of Dreams bản PC (Steam), build **r.1.4.0.13_s** hoặc mới hơn.
> Không cần cài BepInEx/MelonLoader — game có mod loader sẵn.
